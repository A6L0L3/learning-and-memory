## 板块0 · 学习路径和建议

### 0_1 学习路径

1. **先建框架**：读《从平庸到突围》，建立覆盖课堂笔记、会议记录、读书笔记、专业记录四大场景的学习系统。
2. **再专项突破**：读《记忆重构》，把"记不住"拆成可训练的动作，从底层原理练到竞技记忆术。
3. **用自检清单落地**：两篇均配自检清单与案例复盘，读后立刻做第一次自查。
4. **循环迭代**：学习方法靠持续使用与复盘迭代，不建议只"读完"不"练"。

### 0_2 使用建议与边界声明

- 本仓库收录学习方法、记忆训练等内容，仅作为个人成长与学习研究参考，**不构成任何专业教育、医疗或训练指导建议**。相关内容仅供学习参考，请理性看待。
- 本仓库全部文件由公开或原始资料收集而来，并经 AI 工具重新归纳、整理与结构化；整体格式与大纲参考了「庚戊学堂」的学习模块组织方式。原始资料、教材与考纲的著作权归各自权利人所有，本仓库仅对**整理汇编成果**采用 CC BY 4.0（见文末协议）。二创请注明出处，商业使用前请自行确认合规。
